# Аналитический кейс: карты и переводы

Учебный backend для управления банковскими картами. Кейс восстановлен по исходному коду и показывает правила доступа, жизненный цикл карты, перевод между собственными картами, модель данных и HTTP-контракт.

- [Требования и критерии приемки](requirements.md)
- [Процесс и sequence-диаграмма](diagrams.md)
- [Схема данных](data-model.md)
- [API и ошибки](api-spec.md)

Это учебная модель, не банковская система для реальных денег. Карточный номер хранится в базе открытым текстом и маскируется только в ответе API. Отдельного механизма пополнения и журнала переводов нет. Эти ограничения существенны при оценке проекта.
