# HTTP API и ошибки

База маршрутов: `/api`. Для защищенных методов используется `Authorization: Bearer <JWT>`. Код API — источник фактического поведения; существующий [OpenAPI-файл](../openapi.yaml) можно использовать как дополнительную справку.

## Основные методы

| Метод | Доступ | Успешный ответ |
| --- | --- | --- |
| `POST /users` | без токена | 201, текст о созданном пользователе |
| `POST /auth` | без токена | 200, JWT |
| `POST /cards?userId={id}` | `ADMIN` | 201, `CardResponseDto` |
| `GET /cards/all` | `ADMIN` | 200, страница карт |
| `GET /cards/user/{userId}` | `ADMIN` | 200, страница карт пользователя |
| `GET /cards/me` | `USER` | 200, страница своих карт |
| `PATCH /cards/{cardId}/block-request` | `USER` | 200, карта |
| `PATCH /cards/{cardId}/block` | `ADMIN` | 200, карта |
| `PATCH /cards/{cardId}/activate` | `ADMIN` | 200, карта |
| `DELETE /cards/{cardId}` | `ADMIN` | 204 |
| `POST /cards/transfer` | `USER` | 200 без тела |

Списки карт принимают `page` (по умолчанию 0), `size` (10), `direction` (`asc`; `desc` для убывания). Сортировка идет по `id`. `CardResponseDto` содержит `id`, замаскированный `cardNumber`, `expirationDate`, `status`, `balance`.

## Перевод

```json
{"fromCardId": 12, "toCardNumber": "1234567812345678", "amount": 500.00}
```

`fromCardId` обязателен, `toCardNumber` непустой, `amount` положительный. Номер получателя передается целиком, хотя в ответах карт отображается маска. Это ограничение пользовательского сценария: по одному лишь `GET /cards/me` клиент не узнает полный номер карты для перевода.

## Ошибки

`ErrorResponseDto` имеет формат `{"message":"текст ошибки"}`.

| Причина | HTTP | Пример `message` |
| --- | --- | --- |
| Ошибка Bean Validation | 400 | `Сумма перевода должна быть больше нуля` |
| Карта отправителя или получателя не найдена | 404 | `Карта отправителя не найдена` |
| Чужая карта | 400 | `Переводы разрешены только между своими картами` |
| Недостаточно средств | 400 | `Недостаточно средств на карте` |
| Неактивная карта | 400 | `Одна из карт заблокирована, перевод невозможен` |
| Неверный пароль при входе | 401 | `Неверный пароль!` |

Для запроса без токена или без нужной роли ответ формирует Spring Security; единый формат `ErrorResponseDto` для него не гарантирован. Общий обработчик `RuntimeException` возвращает 500 и включает текст исключения в `message`; это текущее поведение, которое не следует считать безопасным публичным контрактом.
